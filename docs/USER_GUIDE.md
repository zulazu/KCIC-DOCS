# KCIC Connect — Panduan Pengguna

Panduan singkat untuk pengguna internal (Employee, Contributor, Unit Manager) pada pilot KCIC Connect.

## 1. Masuk dan keamanan akun

1. Buka alamat KCIC Connect yang diberikan administrator.
2. Masuk dengan **username atau email** dan password dari administrator.
3. Jika akun baru atau password direset, Anda wajib membuat password pribadi terlebih dahulu. Minimal 12 karakter dan tidak boleh sama dengan username/email.
4. Setelah 5 kali salah password, akun terkunci sementara. Hubungi administrator bila perlu dibuka.
5. "Ubah password" di pojok kanan atas mengganti password. Semua session lain milik akun Anda akan berakhir.

Sidebar kiri berisi menu sesuai hak akses Anda. Menu yang tidak muncul berarti Anda tidak memiliki izin; ini bukan error.

## 2. Dashboard

Dashboard menampilkan role, unit kerja, jumlah capability aktif, dan waktu login terakhir. Gunakan ini untuk memastikan Anda masuk dengan akun dan hak yang benar.

## 3. Mencari dan membuka dokumen

1. Buka **Dokumen**.
2. Gunakan kata kunci judul/kode, workspace, kategori, jenis, klasifikasi, atau status. Tekan **Terapkan**.
3. Centang **Tampilkan dokumen arsip** hanya bila Anda perlu melihat dokumen yang sudah diarsipkan.
4. Klik dokumen untuk membuka detail:
   - **Versi aktif** adalah versi resmi yang dipakai katalog dan distribusi.
   - **Riwayat versi** menampilkan versi lama berlabel `SUPERSEDED`; file lama tetap dapat dipreview/diunduh sesuai izin.
   - **Preview** membuka file di browser; **Unduh** menyimpan dengan nama asli.
   - **Favorit** menandai dokumen agar mudah ditemukan di tab "Favorit saya".
5. Bila Anda hanya melihat keterangan "Akses tidak diizinkan" atau dokumen tidak ditemukan pada tautan langsung, berarti Anda belum memiliki akses. Ajukan request.

Setiap preview dan unduhan tercatat pada audit trail.

## 4. Mengajukan request

1. Buka **Requests** → **Request baru**.
2. Pilih tipe: akses dokumen, pengiriman dokumen, atau template.
3. Untuk request akses, pilih dokumen yang Anda butuhkan (wajib).
4. Isi alasan/kebutuhan, unit (bila relevan), dan tanggal dibutuhkan.
5. Kirim. Approver ditentukan otomatis dari pemilik dokumen/unit; Anda akan menerima notifikasi saat diproses.

Pantau di tab **Request saya**. Approver melihat tugasnya di **Tugas saya** dan dapat **Mulai review**, **Setujui**, atau **Tolak** (penolakan wajib alasan). Jika disetujui dan dipenuhi, akses dokumen aktif otomatis dan Anda menerima notifikasi. Setelah selesai, Anda dapat **Tutup** request.

Request dapat **Dibatalkan** selama masih terbuka. Status yang tidak valid tidak dapat dipaksakan; sistem menolak transisi ganda.

## 5. Notifikasi

Ikon lonceng menampilkan jumlah notifikasi belum dibaca. Buka **Notifikasi** untuk:

- membaca detail kejadian (request dikirim/disetujui/ditolak/dipenuhi, distribusi diterima),
- **Buka** untuk menandai sudah dibaca sekaligus menuju halaman terkait,
- **Tandai semua dibaca**.

## 6. Distribusi dokumen

Jika Anda menerima distribusi, buka **Distribusi** → tab **Diterima**. Detail menampilkan dokumen, level akses (lihat/preview/unduh), masa berlaku, dan status Anda. Membuka distribusi menandai status `READ` untuk pengirim.

Akses dari distribusi dapat dicabut atau kedaluwarsa kapan saja oleh pengirim/administrator. Setelah dicabut, percobaan membuka dokumen berikutnya akan ditolak.

## 7. Template

**Template** berisi template resmi yang dipublikasikan. Katalog hanya menampilkan template `PUBLISHED` yang dokumen sumbernya dapat Anda akses. Pada detail:

- versi dengan label **CURRENT** adalah acuan template saat ini,
- versi lama berlabel `SUPERSEDED`; tombol "Unduh versi lama" menampilkan peringatan bahwa versi tersebut **bukan acuan resmi** dan sebaiknya diverifikasi sebelum dipakai,
- jumlah penggunaan bersifat informasi, bukan pemberian akses.

## 8. Bila terjadi masalah

| Gejala | Tindakan |
|---|---|
| Lupa password / akun terkunci | Hubungi administrator untuk reset/pembukaan |
| Dokumen tidak ditemukan padahal Anda butuh | Ajukan request akses; jangan meminta file melalui jalur informal |
| Tombol tidak muncul | Berarti hak akses Anda tidak mencakup tindakan itu; hubungi administrator bila memang dibutuhkan |
| "Akses tidak diizinkan" pada tautan | Akses Anda belum ada/dicabut/kedaluwarsa |
| Unduhan gagal | Ulangi; bila tetap gagal, laporkan ke administrator dengan waktu kejadian |

Aturan penting: jangan membagikan password, jangan menyimpan file sensitif di luar tempat yang disetujui, dan ingat bahwa akses dokumen dapat dicabut kapan saja serta tercatat pada audit.
